Tasmota config for chicken coop door.
Where to connect sensors, buttons, motor shield you can find under Configure module after you flash it.
On motor shield first oputput is for motor to open/close doors, second output is for light - 12V LED.
You can go without buttons or temperature sensor and voltage/current sensor.
In timers you can set time when open/close doors and switch on/off lights.
Outputs relay 1 for open, relay 2 for close, relay 3 for light.
Outputs are interlocked and timer set to 9 seconds to close/open door. You can change it in console.
